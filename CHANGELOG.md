# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [17.0.1.0.0] - 2024-11-16

### Added
- Initial release of Hotel Management module for Odoo 17
- Room management with types, amenities, and status tracking
- Reservation system with automatic pricing and conflict detection
- Customer management with detailed profiles
- Housekeeping task management with priority system
- Dynamic pricing rules (seasonal, weekend, special offers)
- Guest folio/billing system with line-by-line charges
- Meal management (types and orders)
- Transport service booking
- Automated workflows (checkout → housekeeping → available)
- Professional reports (reservation voucher, guest folio, occupancy)
- Multi-user support with role-based access control
- Comprehensive documentation

### Features
- 12 models for complete hotel operations
- 50+ views (tree, form, kanban, calendar)
- 15 menu items with organized navigation
- 3 professional reports
- Automated task creation and status updates
- Real-time room availability tracking
- Payment tracking and balance calculation

### Security
- Three user groups (User, Receptionist, Manager)
- Record-level access rules
- 30+ access control entries

### Documentation
- README with installation and usage instructions
- INSTALLATION guide
- Comprehensive inline code documentation
