### 🎓 QUICK START WITH NEW FEATURES

#### Create Your First Pricing Rule
```
1. Go to: Configuration → Pricing Rules
2. Click "Create"
3. Name: "Weekend Premium"
4. Dates: This year
5. Days: Saturday, Sunday
6. Type: Percentage
7. Value: 20 (for +20%)
8. Save
```

#### Assign a Housekeeping Task
```
1. Go to: Operations → Housekeeping
2. Click "Create"
3. Select Room
4. Task Type: Regular Cleaning
5. Assign To: Staff member
6. Priority: Normal
7. Save
```

#### Create a Guest Folio
```
1. Go to: Operations → Folios/Bills
2. Click "Create"
3. Select Reservation
4. Add Lines:
   - Room charges
   - Meal charges
   - Extra services
5. Confirm
6. Print for guest
```
