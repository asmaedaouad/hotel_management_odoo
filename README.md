# Hotel Management Module for Odoo 17

A comprehensive hotel management system for Odoo 17 that handles all aspects of hotel operations.

## Features

### Core Operations
- Room Management - Room inventory with types, amenities, and status tracking
- Reservation System - Booking workflow with automatic pricing
- Customer Management - Guest profiles with history
- Housekeeping - Task management with priority system
- Folio/Billing - Guest billing with charge tracking

### Services
- Meal Management - Room service and restaurant orders
- Transport Services - Vehicle booking

### Configuration
- Dynamic Pricing Rules - Seasonal pricing and special offers
- Room Types - Room categorization with amenities
- Meal Types - Menu configuration

## Installation

1. Clone the repository
```bash
git clone https://github.com/asmaedaouad/hotel_management_odoo.git
```

2. Copy to Odoo addons directory
```bash
cp -r hotel_management /path/to/odoo/addons/
```

3. Restart Odoo and install the module from Apps menu
