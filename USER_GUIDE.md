# User Guide

## Getting Started

### Initial Setup

1. **Configure Room Types**
   - Go to: Hotel Management → Configuration → Room Types
   - Create room types (Standard, Deluxe, Suite, etc.)
   - Set pricing and amenities

2. **Add Rooms**
   - Go to: Hotel Management → Operations → Rooms
   - Create rooms with room numbers and types

3. **Setup Pricing Rules** (Optional)
   - Go to: Hotel Management → Configuration → Pricing Rules
   - Create seasonal pricing or special offers

## Daily Operations

### Creating a Reservation

1. Go to: Hotel Management → Operations → Reservations
2. Click "Create"
3. Select or create a customer
4. Choose room and dates
5. Enter guest information
6. Click "Confirm"

### Check-In Process

1. Open the reservation
2. Verify guest details
3. Click "Check In" button
4. Room status changes to "Occupied"

### Check-Out Process

1. Open the reservation
2. Click "Check Out" button
3. Room status changes to "Cleaning"
4. Housekeeping task is automatically created

### Managing Housekeeping

1. Go to: Hotel Management → Operations → Housekeeping
2. View tasks in Kanban board
3. Assign tasks to staff
4. Click "Start" when beginning
5. Complete checklist items
6. Click "Complete" when done

### Creating Guest Folio

1. Go to: Hotel Management → Operations → Folios/Bills
2. Click "Create"
3. Select reservation
4. Add charge lines (room, meals, extras)
5. Confirm and print for guest

### Meal Orders

1. Go to: Hotel Management → Services → Meal Orders
2. Create order linked to reservation
3. Add meal items
4. Track order status

### Transport Booking

1. Go to: Hotel Management → Services → Transport
2. Create booking
3. Select customer and vehicle
4. Set pickup details

## Configuration

### Pricing Rules

Create rules for:
- Seasonal pricing (Summer, Winter)
- Weekend rates
- Special offers
- Early bird discounts

Example:
- Name: "Weekend Premium"
- Dates: Year-round
- Days: Saturday, Sunday
- Type: Percentage
- Value: +20%

### Room Types

Configure:
- Name and code
- Capacity
- Base price
- Bed type
- Size
- Amenities

### Meal Types

Setup:
- Name and category
- Price
- Availability hours
- Dietary information

## Reports

### Reservation Voucher
- Open reservation → Print → Reservation Voucher

### Guest Folio
- Open folio → Print → Guest Folio

## User Roles

### Hotel User
- View reservations
- Create bookings

### Hotel Receptionist
- Manage reservations
- Check-in/out guests
- Create folios
- Manage housekeeping

### Hotel Manager
- Full access
- Configure pricing
- Manage all operations
- View reports

## Tips

- Always confirm reservations (don't leave in Draft)
- Check in guests on arrival
- Check out guests on departure
- Use housekeeping tasks for room management
- Track all charges in folios
- Review pricing rules regularly
